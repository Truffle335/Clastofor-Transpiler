# Clastofor Update Log

## Version 1.1

### Release date
- 2026-10-09

### Included features
- Boolean type support: `bool`
- Boolean literals: `true` and `false`
- Conditional statements: `if (...) { ... } else { ... }`
- Comparison operators: `>`, `<`, `>=`, `<=`, `==`, `!=`
- Variable declarations for `int`, `float`, `str`, and `bool`
- Console output via `console.print(...)`
- Console input via `console.input(...)`
- Basic arithmetic: `+`, `-`, `*`, `/`, `%`
- Division-by-zero checks
- Basic error reporting with line numbers
- Transpilation into readable C++17 code
- Executable generation and execution

### Current status
Clastofor v1.1 adds conditional logic and boolean evaluation to the language while keeping the system small, readable, and easy to extend.
