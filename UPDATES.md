# UPDATES

Current version: 1.2.2

---

### 1.0
First release of the language. This version implemented the base types int, str, float, arithmetic operators + - * / %, and the functions console.print() and console.input().

### 1.1
This version implemented conditional constructs if () {} else {}, the boolean type bool with the values true and false, and the comparison operators == != > < >= <=.

### 1.2
This version implemented the logical operators || and &&, the import keyword, and the random module with the functions random.random.int(), random.random.float(), and random.random.bool().

### 1.2.1
This version fixed the Clastofor error handler.

### 1.2.2
This version fixed a bug with console.input() that always returned a value of type str, regardless of the declared variable type.
