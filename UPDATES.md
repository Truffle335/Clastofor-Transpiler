# Clastofor Update Log

## Version 1.0

### Release date
- 2026-10-08

### Included features
- Variable declarations for `int`, `float`, and `str`
- Console output via `console.print(...)`
- Console input via `console.input(...)`
- Basic arithmetic: `+`, `-`, `*`, `/`, `%`
- Division-by-zero checks
- Basic error reporting with line numbers
- Transpilation into readable C++17 code
- Executable generation and execution

### Current status
Clastofor v1.0 is a minimal, working language. It does what it's designed to do: simple variables, I/O, and arithmetic, compiled to fast C++ code.
